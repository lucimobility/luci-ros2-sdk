How it fits

LuciCore is LUCI's safety layer. Its Nav, Safety and Sensors tiers sit between your software and the motors: your software sends intent through the SDK, and LuciCore decides how the machine moves safely.

  1. Your softwarePlanner, VLA, teleop, or a person
  2. LUCI SDKDrive intent and sensor data
  3. LuciCoreNavSafetySensors
  4. MotorsThe machine moves

Any brain can drive. LuciCore always has the final say on safety.

LUCI SDK

One SDK, with an API for each kind of thing that crosses into LuciCore.

APIWhat crosses itAvailable through
Drive intent Drive-path intent from any brain. LuciCore bounds it. ROS2 SDK
Sensor data Point clouds, odometry and joystick position, in and out. Raw from the sensors, or filtered and processed by LUCI's proprietary algorithms, such as collision and drop-off detection. ROS2 SDK
Input devices Wheelchair only Drive input from devices such as game controllers, adaptive controllers and Apple Vision Pro, connected through the LuciLink Hub. WDI spec

Install the ROS2 packages

The ROS2 SDK runs on Ubuntu 22.04 with ROS2 Humble on amd64. Add the LUCI apt repository and install the packages you need. See the installation guide for pinning the versions of an SDK release.

curl -fsSL https://sdk.luci.com/ros2/apt/luci-ros2-archive-keyring.gpg | sudo tee /usr/share/keyrings/luci-ros2-archive-keyring.gpg > /dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/luci-ros2-archive-keyring.gpg] https://sdk.luci.com/ros2/apt jammy main" | sudo tee /etc/apt/sources.list.d/luci-ros2.list > /dev/null
sudo apt update
sudo apt install ros-humble-luci-messages ros-humble-luci-grpc-interface ros-humble-luci-transforms

LuciCore runs on Linux together with real-time processors, needs little compute, and can be tailored to most robotics compute platforms. It ships today on NXP i.MX and is proven on NVIDIA Jetson.

Research Sandbox

The ROS2 SDK runs against a LUCI Dev Kit: a LUCI-enabled power wheelchair running LuciCore Sandbox Edition. Sandbox Edition is for research, not commercial use. To join the program as a Sandbox Partner, contact info@luci.com.

Moving to production, or building a robot?

LuciCore is designed to be brain-agnostic: bring your planner, model or teleop, and your sensors or ours. The Dev Kit's sensors are available as an optional reference kit. FAQ

What is LuciCore?

LuciCore is LUCI's safety layer. Its Nav, Safety and Sensors tiers take drive intent from any source and keep the machine moving safely among people. It has shipped on power wheelchairs since 2020 and is developed under IEC 62304.

What do I need to use the SDK?

Today the SDK runs against a LUCI Dev Kit, a LUCI-enabled power wheelchair running LuciCore Sandbox Edition, and a development machine with Ubuntu 22.04 and ROS2 Humble.

Can I use Sandbox Edition commercially?

No. Sandbox Edition is for research only. Commercial use of LuciCore goes through a paid design partnership; contact info@luci.com to start one.
